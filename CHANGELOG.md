# Журнал изменений

Все значимые изменения проекта фиксируются в этом файле.

Формат основан на Keep a Changelog, проект следует Semantic Versioning.

## [1.1.7] - 2026-09-13

### Исправлено

- Исправлен ввод минут в Windows-версии: Tk-диалог перенесен в отдельный Tk-поток с постоянным скрытым корневым окном, а меню трея больше не блокируется при открытии окна. pystray и Tk больше не конкурируют за один поток, поэтому поле ввода корректно получает клавиатурный фокус на Windows 10/11 без Win32-хаков с `SetForegroundWindow`.
- Открытие диалога теперь асинхронное: пункт меню `Минуты:` ставит команду в очередь, которую обрабатывает Tk-поток; результат применения значения и обновления меню возвращается после закрытия окна.
- Добавлены регрессионные тесты новой архитектуры: постановка команды в очередь, обработка в Tk-потоке, применение/отмена значения, фокус поля ввода, завершение приложения.

## [1.1.6] - 2026-09-13

### Исправлено

- Исправлен ввод минут в Windows-версии: значение в поле ввода теперь можно набирать сразу после открытия окна. Помимо Tk-вызовов фокуса, окно дополнительно активируется через Win32 API `SetForegroundWindow` с привязкой к входной очереди текущего foreground-окна, поэтому клавиатура корректно направляется в `Entry` на Windows 10/11.
- Добавлены регрессионные тесты активации диалога: обновление окна перед фокусом, вызов foreground-активации, фокус поля ввода, выделение текущего значения и fallback на некорректный/отсутствующий Win32-вызов.

## [1.1.5] - 2026-09-13

### Исправлено

- Исправлена невозможность редактировать значение минут в Windows portable-версии: `simpledialog.askinteger` заменен явным Tk-диалогом с полем ввода, которое получает фокус и позволяет заменить текущее значение.
- Добавлены регрессионные тесты Windows-диалога: фокус поля ввода, выделение текущего значения, подтверждение через Enter/OK, отмена через Escape/крестик, ограничение диапазона и обработка нечислового ввода.

## [1.1.4] - 2026-05-15

### Исправлено

- Исправлен фокус окна ввода минут в Windows: перед открытием диалога вызываются `lift`, `focus_force` и `update`, поэтому поле ввода корректно принимает нажатия клавиатуры.
- Обновлены тесты Windows-диалога ввода минут: добавлены проверки вызова `lift`, `focus_force` и `update`.

## [1.1.3] - 2026-05-13

### Исправлено

- Исправлен ввод пользовательского интервала в Windows portable-версии: пункт `Минуты:` теперь открывает окно ввода в текущем процессе вместо запуска подпроцесса через `sys.executable`.
- Добавлена защита от повторного открытия окна ввода минут и улучшена обработка случая, когда `tkinter` недоступен.
- Добавлены тесты для Windows-диалога ввода минут: успешный ввод, отмена, ограничения диапазона, конкурентный вызов и отказ при отсутствии `tkinter`.

## [1.1.2] - 2026-05-13

### Исправлено

- Исправлена публикация Windows установщика в релизе: `move-reminder-setup.exe` теперь создается в `dist/` репозитория и корректно подхватывается шагом загрузки артефактов.
- Добавлена явная проверка наличия `dist/move-reminder-setup.exe` в Windows release workflow перед публикацией.

## [1.1.1] - 2026-05-13

### Исправлено

- Исправлена сборка Windows portable-бинарника в GitHub Actions: путь к `timer_tray.py` в PyInstaller spec теперь корректно резолвится из корня репозитория.

## [1.1.0] - 2026-05-13

### Добавлено

- Поддержка Windows 10/11: отдельный tray-backend на `pystray` с уведомлениями и звуком.
- Сборка Windows portable-бинарника (`move-reminder-portable.exe`) через PyInstaller.
- Сборка Windows установщика (`move-reminder-setup.exe`) через Inno Setup.
- Автоматический GitHub Actions релиз Windows-артефактов по тегам `v*`.

### Изменено

- README обновлен под кроссплатформенный сценарий (Linux + Windows).
- Улучшена стабильность Windows-пайплайна: проверка артефакта перед упаковкой, фикс путей Inno Setup, отключен UPX.

## [1.0.0] - 2026-05-05

### Добавлено

- Первичная версия tray-таймера для Ubuntu GNOME.
- Debian-пакетирование и launcher для запуска установленного приложения.
- Автоматические CI-проверки Python-кода, shell-скриптов и desktop-файлов.
- Базовый набор `pytest`-тестов для логики таймера и fallback-цепочки звука.
- Инструкции для AI-агентов и переиспользуемые skills для проверок и релизного процесса.

### Изменено

- Усилена обработка single-instance lock и завершения таймера с уведомлением.
- Обновлена конфигурация GitHub Actions для совместимости с Node 24.
