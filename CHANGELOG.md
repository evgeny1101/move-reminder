# Журнал изменений

Все значимые изменения проекта фиксируются в этом файле.

Формат основан на Keep a Changelog, проект следует Semantic Versioning.

## [1.0.0] - 2026-05-05

### Добавлено

- Первичная версия tray-таймера для Ubuntu GNOME.
- Debian-пакетирование и launcher для запуска установленного приложения.
- Автоматические CI-проверки Python-кода, shell-скриптов и desktop-файлов.
- Базовый набор `pytest`-тестов для логики таймера и fallback-цепочки звука.
- Инструкции для AI-агентов и переиспользуемые skills для проверок и релизного процесса.

### Изменено

- Усилена обработка single-instance lock и завершения таймера с уведомлением.
- Обновлена конфигурация GitHub Actions для совместимости с Node 24.
